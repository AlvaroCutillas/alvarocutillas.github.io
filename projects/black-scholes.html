01 / Research question

Can a simple model be validated rigorously?

The project asks whether one no-dividend Black–Scholes implementation prices European options consistently, whether its Greeks survive numerical differentiation, and whether Monte Carlo uncertainty behaves as theory predicts.

What I built

Closed-form call and put prices; Delta, Gamma, Vega, Theta and Rho; Brent implied-volatility inversion; standard, antithetic and independently piloted control-variate simulation; 49 automated test cases; seven illustrative scenarios; and eleven generated figures.

What the evidence establishes

Formula identities, boundary behavior, derivative checks and seeded simulation results are consistent with the implemented model. They establish numerical self-consistency for the tested cases—not fit to observed option markets or profitable hedging.

The benchmark holds S=K=100, T=1 year, r=0.05 and σ=0.20. All monetary outputs use the same unspecified currency unit as the stock and strike. Values are calculated at full floating-point precision and rounded here for presentation.

02 / Mathematical framework

The model, from process to price

Under the physical probability measure, geometric Brownian motion assumes a proportional stock return with constant drift and volatility. For pricing, a continuously rebalanced Delta hedge eliminates the instantaneous Brownian exposure. In a frictionless market, no arbitrage then requires the hedged portfolio to earn the risk-free rate. This produces the Black–Scholes PDE and an equivalent risk-neutral expectation.

dSt = μStdt + σStdWt
∂tV + 12σ²S²∂SSV + rS∂SV − rV = 0

Under the risk-neutral measure Q, the model drift becomes r. The drift substitution is a pricing result, not a claim that the stock's real-world expected return equals the risk-free rate.

ST = S0 exp[(r − 12σ²)T + σ√T Z],   Z ~ N(0,1)
V0 = e−rTEQ[payoff(ST)]

Closed-form European prices

d1 = ln(SK) + (r + 12σ²)Tσ√T
d2 = d1 − σ√T
C = S N(d1) − Ke−rTN(d2)
P = Ke−rTN(−d2) − S N(−d1)

N is the standard normal CDF. N(d₂) is the risk-neutral call exercise probability in this model; N(d₁) arises from the stock-weighted truncated lognormal expectation and equals the no-dividend call Delta. At the benchmark, the computed values are C = 10.451 and P = 5.574.

Boundary handling. The closed forms divide by σ√T. At T=0, the code returns intrinsic payoff. At σ=0, it discounts the deterministic payoff. It does not evaluate d₁ or d₂ at those singular inputs.

03 / Local sensitivities

What the five Greeks measure

Each Greek changes one input while holding the others fixed. The raw derivatives below use decimal rates and volatility. Theta is −∂V/∂T: calendar-time decay per year, so it has the opposite sign from a maturity derivative. The first-order interpretation is local; large market moves require repricing.

Delta · directional exposure

A call Delta of 0.637 means a small one-unit rise in spot changes the benchmark call value by approximately 0.637 currency units, with other inputs fixed. Put Delta is negative. In the idealized model, Delta is the instantaneous share hedge.

Gamma · hedge curvature

Gamma is the rate at which Delta changes with spot. It is positive for both vanilla calls and puts. It is concentrated near the exercise region, where small spot moves most alter exercise likelihood. Its peak is generally near, but not exactly at, S=K.

Vega · volatility exposure

Positive Vega reflects the convexity of option payoffs: raising volatility while holding the forward fixed raises a European vanilla option's value. The benchmark raw Vega of 37.524 corresponds to about 0.375 currency units for a one percentage point volatility increase.

Theta and Rho · time and rates

Benchmark call Theta is -6.414 per calendar year (about -0.018 per day using 365 days). Call Rho is 53.232 per 1.00 rate change, or 0.532 for one percentage point. Sign patterns can change outside this benchmark.

The plots vary only spot, keeping K=100, T=1, r=0.05 and σ=0.20. The formulas define Greeks only for T>0 and σ>0; the exact boundaries can be nondifferentiable.

04 / Inverse problem

Recovering implied volatility

Implied volatility asks which σ makes the model price equal a supplied option price. The implementation solves BS(σ) − market_price = 0 with Brent's bracketed root method. It checks the no-arbitrage price range first, allows a configurable volatility bracket, and reports failure if that bracket cannot contain a root.

max(S − Ke−rT, 0) ≤ C < S   and   max(Ke−rT − S, 0) ≤ P < Ke−rT

For positive maturity, Vega is positive in the smooth interior, so the vanilla model price is continuous and strictly increasing in volatility. This supplies uniqueness whenever the quote is between the zero-volatility price and the limiting upper price. A price at the lower bound maps to zero volatility. At expiry, volatility is not identifiable.

Numerical recovery check
20.00%
Recovered σ from the synthetic 20% benchmark call

The test confirms inversion of this implementation's own price. It is an internal consistency check, not evidence that the model fits a market quote.

Where inversion becomes fragile

Deep in or out of the money, or near expiry, Vega can be tiny. A small quote or floating-point error then produces a large change in implied volatility. Bad quotes, a too-narrow bracket and solver nonconvergence are handled explicitly.

05 / Experimental design

Monte Carlo as an independent pricing route

The simulation draws standard normals with NumPy's seeded Generator, converts them to risk-neutral terminal stock prices, applies the European call or put payoff and discounts by e−rT. The benchmark analytical price is the reference for error measurement.

Yi = e−rT payoff(ST,i)
V̂ = ΣYin,   SÊ = sY√n
CI95% ≈ V̂ ± 1.96 SÊ

The sample standard deviation uses ddof=1. The normal interval is asymptotic: it describes a procedure that would cover the fixed model price in roughly 95% of repeated comparable experiments when its assumptions hold. It does not guarantee coverage in this realized run.

A / Standard

Independent payoffs

Generate N independent terminal prices. The observation count for the standard error is N.

B / Antithetic

Normal pairs

For each Z, also simulate −Z and average the two payoffs. N terminal payoffs produce half as many independent pair averages. Opposite draws tend to give negatively correlated monotone vanilla payoffs.

C / Control variate

Known stock expectation

Subtract β(e−rTST−S), whose model expectation is zero. Estimate β on a separate 5,000-path pilot, then price from 100,000 independent main paths. The extra pilot cost is counted.

Antithetic pairing preserves unbiasedness because both Z and −Z have standard-normal marginals. Their negative payoff covariance reduces the variance of the pair average:

Var(Y(Z) + Y(−Z)2) = Var(Y) + Cov(Y(Z), Y(−Z))2

The control estimate is unbiased conditional on its independent pilot coefficient; its reported SE comes from the main adjusted payoffs.

08 / Numerical validation

Multiple checks, different failure modes

C − P = S − Ke−rT   ·   benchmark residual = 0.0

Put-call parity and static bounds check relationships that must hold for this no-dividend European model. Monotonicity checks confirm that calls rise with spot, puts fall with spot, and both rise with volatility in the tested scenarios. Gamma is non-negative. Limiting tests cover expiry, zero volatility, small maturity and volatility, and deep in/out-of-the-money cases.

Analytical Greeks are checked against central differences of the pricing function. The spot derivatives use:

Δ ≈ V(S+h) − V(S−h)2h
Γ ≈ V(S+h) − 2V(S) + V(S−h)h²

The default spot step is 0.1% of spot; volatility, rate and maturity steps are 10⁻⁴ in their respective units. Theta uses the negative maturity derivative to match calendar-time decay.

09 / What the results can and cannot say

Reliability, assumptions and market limits

The experiments validate a model implementation under its own assumptions. Their precision measures simulation noise conditional on those assumptions; it does not measure how far the model may be from real traded prices.

AssumptionWhat it enables hereWhere real markets differ
Geometric Brownian motion; lognormal terminal pricesClosed-form vanilla prices and exact terminal simulationFat tails, jumps and crash risk can make tail payoffs materially different.
Constant volatilityOne σ across strikes and maturityObserved option surfaces exhibit smile, skew and changing volatility.
Constant continuously compounded rate; zero dividendsSimple discounting and forward drift rTerm structures, dividends, borrow costs and other carry affect prices.
Frictionless continuous trading and hedgingExact PDE replication in the idealized modelDiscrete rebalancing, bid/ask spreads, liquidity and transaction costs create hedging error.
European exercise; no jumps or stochastic volatilityTerminal-payoff pricing in the stated formulaEarly exercise, discontinuities and volatility dynamics require other models and methods.

Three distinct kinds of uncertainty

Simulation noise

Estimated by Monte Carlo standard errors and asymptotic intervals. It decreases with more independent observations, approximately as N⁻¹ᐟ².

Input and quote error

Rates, volatility and any market option quote can be uncertain or stale. The project does not estimate bid/ask, calibration or data-cleaning error.

Model error

Constant-volatility lognormal dynamics can be structurally wrong even if the formulas, code and simulation are numerically exact.

Confidence intervals on simulated prices quantify the first category only. Implied volatility is a model-dependent translation of a quote, not a direct observation of future realized volatility. The project uses synthetic model-consistent inputs rather than a historical options dataset, so no out-of-sample pricing or hedging performance claim follows.

10 / Reproducibility

How to inspect and rerun the research

The source separates pricing, Greeks, volatility inversion, Monte Carlo, validation and plotting. The analysis runner writes full-precision CSV/JSON outputs and eleven PNG figures. Fixed NumPy seeds reproduce estimates under the tested dependency versions; bitwise agreement across future library versions is not guaranteed. Runtime varies with hardware and system load.

python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pytest --assert=plain tests -q
python -m analysis.run_analysis

Run these commands from the repository root in Windows PowerShell. The project requires Python 3.10 or newer. The full source archive is supplied alongside this standalone page; a public GitHub URL has not yet been assigned.

Implementation

src/black_scholes.py, greeks.py, implied_volatility.py, monte_carlo.py, validation.py and visualization.py.

Evidence

analysis/run_analysis.py, four pytest modules, results/summary.json, four CSV tables and the eleven generated figures.

11 / Conclusion

A defensible benchmark, with visible limits

The implementation reproduces the Black–Scholes benchmark, satisfies tested no-arbitrage identities, recovers its own volatility input and produces Monte Carlo standard errors near the predicted inverse-square-root scaling.

At equal 100,000-path call budgets, antithetic sampling cut estimated variance by 50.1%; the independently piloted control cut it by 85.4% while using 5,000 additional paths. The one-million-path standard interval missed the analytical value, and realized errors were not monotone. Both observations belong in the result, because a credible quantitative project must distinguish mathematical expectation, estimated uncertainty and a particular random outcome.

The next meaningful research step would use screened market quotes with bid/ask information, compare the implied-volatility surface with constant-σ predictions, and evaluate discrete hedging error. Those tasks require new data and assumptions; they are not claimed by this model validation project.
