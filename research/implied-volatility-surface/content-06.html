Study 3: analytical bounds and density moments

With \(\eta=2.3\) and \(\rho=-0.65\), the all-maturity wing expression is 3.795, strictly below four. The global curvature expression is 2.182125, below four. Positive scales and the chosen shape function satisfy the sufficient calendar condition. The reference family is therefore certified within the stated European deterministic-carry framework.

Study 4: an intentionally invalid shape

Keep the reference ATM term structure and \(\rho\), but set \(\eta=12\). ATM IV is unchanged because \(\theta\) is unchanged. The wings steepen and the \(g\) diagnostic becomes negative in part of the domain. The example demonstrates why checking positive IV or exact ATM calibration alone misses butterfly inconsistencies.

Restore the reference parameters before interpreting local volatility. In an invalid region, negative density or derivative ratios cannot be converted into a meaningful diffusion coefficient merely by taking an absolute value.

28 / Appendix

Mathematical appendix and reference implementation

SSVI derivatives for the reference family

Set \(\theta=\theta(T)\), \(p=\eta/(1+\theta)\), \(u=pk+\rho\) and \(z=\sqrt{u^2+1-\rho^2}\). The total variance and its strike derivatives are:

\[ w=\frac{\theta}{2}(1+\rho pk+z),\qquad w_k=\frac{\theta p}{2}\left(\rho+\frac{u}{z}\right),\qquad w_{kk}=\frac{\theta p^2(1-\rho^2)}{2z^3}. \]

For the time derivative, hold \(k\) fixed and first differentiate in \(\theta\):

\[ w_\theta=\frac{1+\rho pk+z}{2} -\frac{\theta\eta k}{2(1+\theta)^2}\left(\rho+\frac{u}{z}\right), \qquad w_T=w_\theta\theta'(T). \]

These formulas avoid finite-difference noise. Independent differences of the original \(w\) can check them. At \(k=0\), they reduce to \(w=\theta\), \(w_k=\theta p\rho\), \(w_{kk}=\theta p^2(1-\rho^2)/2\) and \(w_T=\theta'(T)\).

Relation to raw SVI

At a fixed expiry and positive \(p\), a reference SSVI slice can be represented exactly as raw SVI with:

\[ a=\frac{\theta(1-\rho^2)}{2},\quad b_{\mathrm{SVI}}=\frac{\theta p}{2},\quad m=-\frac{\rho}{p},\quad s=\frac{\sqrt{1-\rho^2}}{p}. \]

Substitution into the raw formula recovers the same \(w\). This equivalence explains why a raw SVI optimizer can fit a noise-free reference slice exactly. It does not imply that all raw SVI parameter sets satisfy the cross-expiry structure or certificates used by this family. At \(\eta=0\), the smile is constant and the formulas involving \(1/p\) should be replaced by that flat limit.

Finite-horizon sufficient expressions

Let \(\Theta=\theta(H)\) and \(a_*=\min(\Theta,1)\). The maximal butterfly expressions over \(0<T\le H\) are:

\[ B_1(H)=\frac{\eta\Theta}{1+\Theta}(1+|\rho|),\qquad B_2(H)=\frac{\eta^2a_*}{(1+a_*)^2}(1+|\rho|). \]

The second expression uses \(a_*\) because \(x/(1+x)^2\) rises until one and then falls. Testing only the last expiry for this condition would be incorrect once \(\theta(H)>1\). The laboratory checks the true interval maximum.

A compact Python reference

The following implementation uses standard-library functions for central-region prices and a bracketed inverse. It is intended as a transparent reference, not a replacement for stable special-function implementations in extreme tails. Premiums, forwards and volatilities use the same units as the laboratory.

from math import erf, exp, expm1, log, sqrt, pi

def normal_cdf(x):
    return 0.5 * (1.0 + erf(x / sqrt(2.0)))

def black_price(F, K, D, T, sigma, put=False):
    if sigma == 0:
        return D * max(K-F if put else F-K, 0.0)
    root = sigma * sqrt(T)
    d1 = log(F/K) / root + root/2
    d2 = d1 - root
    if K >= F:
        c = D * (F*normal_cdf(d1) - K*normal_cdf(d2))
        return c + D*(K-F) if put else c
    p = D * (K*normal_cdf(-d2) - F*normal_cdf(-d1))
    return p if put else p + D*(F-K)

def implied_vol(price, F, K, D, T, put=False):
    assert min(F, K, D, T) > 0
    low = D * max(K-F if put else F-K, 0.0)
    high = D * (K if put else F)
    if not low <= price < high:
        raise ValueError("Outside the finite-IV domain")
    if price == low:
        return 0.0
    a, b = 0.0, 0.5
    while black_price(F, K, D, T, b, put) < price and b < 16:
        b *= 2
    if black_price(F, K, D, T, b, put) < price:
        raise ValueError("Root exceeds volatility cap")
    for _ in range(90):
        m = (a+b)/2
        if black_price(F, K, D, T, m, put) < price:
            a = m
        else:
            b = m
    return (a+b)/2

def reference_sample(k, T, vs=.24, vl=.18,
                     decay=1.2, rho=-.65, eta=2.3):
    theta = vl*vl*T + (vs*vs-vl*vl)*decay*(-expm1(-T/decay))
    p = eta/(1+theta)
    u = p*k + rho
    z = sqrt(u*u + 1-rho*rho)
    w = theta/2*(1+rho*p*k+z)
    wk = theta*p/2*(rho+u/z)
    wkk = theta*p*p*(1-rho*rho)/(2*z**3)
    wt = ((1+rho*p*k+z)/2
          - theta*eta*k*(rho+u/z)/(2*(1+theta)**2))
    wt *= vl*vl + (vs*vs-vl*vl)*exp(-T/decay)
    g = (1-k*wk/(2*w))**2 - wk*wk/4*(1/w+.25) + wkk/2
    return {"w": w, "iv": sqrt(w/T), "g": g,
            "local": sqrt(wt/g) if g > 0 and wt > 0 else None}

T = 1.0
F, D = 100*exp(.02*T), exp(-.03*T)
s = reference_sample(0.0, T)
premium = black_price(F, F, D, T, s["iv"])
assert abs(implied_vol(premium, F, F, D, T)-s["iv"]) < 1e-10
print(s, premium)

Suggested independent checks

Compare premiums and inversions with a different normal-CDF and root-solving implementation. Check parity at varied strikes, analytic derivatives against central differences, density against a finite-difference call curvature, and local variance against the fixed-strike Dupire formula including carry. Verify that changing spot at fixed \(k\) changes strike proportionally without changing the specified IV.

Finally, inspect both ordinary and limiting cases: flat smiles, extreme skew, very short expiries, negative rates, exact intrinsic values and selected maturities outside the declared horizon. A transparent failure state is part of a correct implementation.

29 / Exercises

Exercises and worked solutions

Use decimal volatility in calculations and distinguish a volatility point from a variance unit. The solutions make the conventions and intermediate steps explicit.

Exercise 1 — Finite-IV price bounds

For \(F=100\), \(K=110\), \(D=0.98\) and \(T=0.5\), identify the finite-IV domains of call and put premiums. Does a call premium of 99 admit a finite Black IV?

Solution. The call domain is \(\text{[0,98)}\). The put domain is \(\text{[9.8,107.8)}\). A call at 99 is above the upper bound and has no finite implied volatility. A call at exactly 98 also lacks a finite root, while zero is the intrinsic-limit case.

Exercise 2 — Premium error and vega

A premium has half-spread 0.05 and vega 25 per unit decimal volatility. Estimate its IV half-width in percentage points and basis points.

Solution. \(0.05/25=0.002\) decimal volatility. This is 0.2 volatility percentage points or 20 IV basis points. The calculation is a local first-order approximation.

Exercise 3 — Log-forward moneyness

With spot 100, \(r=3\%\), \(q=1\%\), \(T=1\) and strike 110, calculate the forward and \(k\).

Solution. \(F=100e^{0.02}\approx102.020134\). Then \(k=\ln(110/102.020134)=\ln(1.1)-0.02\approx0.0753102\). Using \(\ln(110/100)\) would ignore the forward carry shift.

Exercise 4 — Falling volatility and positive forward variance

Six-month ATM IV is 30%; one-year ATM IV is 25%. Find both total variances and the incremental variance rate in the flat-smile deterministic-volatility interpretation.

Solution. \(w_1=0.5(0.30)^2=0.045\), \(w_2=(0.25)^2=0.0625\). Incremental variance is \(0.0175/0.5=0.035\); its volatility scale is \(\sqrt{0.035}\approx18.7083\%\). Annualized IV falls while accumulated variance increases.

Exercise 5 — A calendar inconsistency

Replace the one-year IV in Exercise 4 with 18%. Does the pair pass ATM total-variance ordering under the framework in Chapter 12?

Solution. One-year variance is 0.0324, below the six-month 0.045. The incremental difference is negative, so the pair violates the required calendar ordering at \(k=0\). Positive IV at both maturities is insufficient.

Exercise 6 — Forward inference from parity

At strike 100, \(C=8\), \(P=6\) and \(D=0.98\). Infer the forward. If each premium has a bid–ask half-width of 0.10, find the parity interval.

Solution. The midpoint forward is \(100+2/0.98\approx102.040816\). The lower uses call bid 7.9 and put ask 6.1: \(100+1.8/0.98\approx101.836735\). The upper uses call ask 8.1 and put bid 5.9: \(100+2.2/0.98\approx102.244898\).

Exercise 7 — Irregular-strike butterfly test

Call premiums are 12, 8 and 6 at strikes 90, 100 and 120. Check consecutive slopes. What changes if the last premium is 1?

Solution. Slopes are −0.4 and −0.1, so they increase and satisfy discrete convexity. With the last price 1, the second slope is −0.35, still above −0.4 and therefore still convex. The unequal strike spacing must be used; a symmetric unweighted second difference would mischaracterize the geometry.

Exercise 8 — Raw SVI minimum

For \(a=0.01,b=0.05,\rho=-0.6,m=0.02,s=0.2\), calculate the location and value of minimum total variance.

Solution. \(\sqrt{1-\rho^2}=0.8\). The minimum is at \(0.02-(-0.6)(0.2)/0.8=0.17\). Its value is \(0.01+0.05(0.2)(0.8)=0.018\). The minimum does not occur at \(m=0.02\).

Exercise 9 — Raw SVI wing slopes

Use Exercise 8's parameters to find the left and right slopes. Does passing a slope bound of two prove butterfly freedom?

Solution. Left slope is \(0.05(1.6)=0.08\); right slope is \(0.05(0.4)=0.02\). Both are below two. This passes a tail-related restriction but does not prove that \(g(k)\) is nonnegative in the center or that another expiry is calendar consistent.

Exercise 10 — Global sufficient SSVI bounds

With \(\eta=2.3,\rho=-0.65\), calculate the two global expressions for the reference shape function. Repeat with \(\eta=4\).

Solution. The expressions are \(2.3(1.65)=3.795\) and \(2.3^2(1.65)/4=2.182125\), both passing. For eta 4 they are 6.6 and 6.6, both failing. Failure means this sufficient certificate is unavailable; direct negative-density evidence requires evaluating the surface.

Exercise 11 — A maximum before the last expiry

For \(\theta(H)=2\), at which total variance does the curvature expression \(\eta^2\theta(1+|\rho|)/(1+\theta)^2\) attain its maximum over the horizon?

Solution. Differentiating \(\theta/(1+\theta)^2\) gives \((1-\theta)/(1+\theta)^3\). The maximum occurs at \(\theta=1\), not at the terminal value two. Its value is \(\eta^2(1+|\rho|)/4\). Checking only the last expiry would understate it.

Exercise 12 — Surface-aware delta

At spot 100, Black delta is 0.55, vega is 40 per unit volatility and \(\sigma_k=-0.10\). Calculate sticky log-moneyness delta when the forward is proportional to spot.

Solution. Delta is \(0.55-(40/100)(-0.10)=0.59\). Sticky strike would retain 0.55. The difference comes from the assumed smile response, not from a change in the initial contract.

Exercise 13 — Density and local volatility

At a surface point, \(g=-0.02\) and \(w_T=0.04\). Can the ratio \(w_T/g\) be interpreted as local variance? What does the sign reveal?

Solution. The ratio is negative and is not a valid diffusion variance. The same negative \(g\) implies a negative risk-neutral strike density, exposing a butterfly inconsistency. Taking an absolute value would change the model and conceal the error.

Exercise 14 — Interpolation evidence versus a forecast

A model fits 13 strikes and prices four withheld strikes from the same snapshot accurately. What has been tested, and what remains untested?

Solution. The experiment tests interpolation across strikes under the chosen data and inputs. It does not test future smile dynamics, realized volatility forecasting, execution profit or path-dependent pricing. Additional later snapshots, dynamic assumptions and application-specific experiments are needed for those claims.
