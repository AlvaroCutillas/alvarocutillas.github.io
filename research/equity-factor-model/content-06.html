26 / Numerical laboratory

Interactive attribution and portfolio laboratory

Two experiments separate return attribution from characteristic-based selection. They run locally on embedded synthetic observations. Neither requires market-data access or a network connection.

Experiment A: estimate return sensitivities

Choose the portfolio's generating exposures, monthly alpha and innovation scale. These parameters generate a portfolio return from five fixed factor series and a fixed disturbance path. Fit either the market-only benchmark or the full style model, using the selected training prefix.

The subsequent months remain withheld. Fitted coefficients combine with realized factor returns to provide ex post holdout attribution. The tool does not forecast next month's factors in advance. Alpha, classical and HAC uncertainty, training fit and withheld error are reported with their units.

Changing the HAC lag count changes standard errors but leaves coefficients unchanged. Changing a generating style exposure still changes the target when the selected regression is market only; the omitted influence remains in that benchmark's residual.

Experiment B: form a characteristic portfolio

Select a formation score and tail size. Unrestricted tails rank the whole universe. Sector-balanced tails select high and low stocks inside each of four sectors and allocate equal gross capital to each sector. Both constructions have long weights summing to one and short weights summing to minus one.

The next-month returns are observed after weights are selected. The resulting gross return is reduced by one-time entry cost. Pearson and rank IC use the entire formation cross-section, while portfolio returns use only selected tails. The exposure table shows characteristic scores and sector weights, rather than regression betas.

Suggested experiments

  1. Fit the full reference model, then select market only. Compare alpha and withheld RMSE without changing the generating portfolio.
  2. Set noise to zero in the full model. The generating coefficients are recovered to numerical precision; statistical uncertainty then becomes degenerate rather than infinitely informative.
  3. Shorten the training sample and inspect coefficient uncertainty. More observations improve identification under this stable simulation, although actual structural change can alter that trade-off.
  4. Raise the HAC bandwidth. Verify that the point estimates stay fixed while the alpha standard error changes.
  5. Compare unrestricted and sector-balanced value tails. Inspect other characteristic exposures as well as sector neutrality.
  6. Increase entry cost and observe the exact cost deduction. This is a single-entry illustration, not a complete strategy backtest.

28 / Mathematical appendix

Mathematical appendix and reference implementation

OLS and orthogonality

Differentiating squared error gives the normal equations:

\[ \frac{\partial}{\partial b}(y-Xb)^{\mathsf T}(y-Xb) =-2X^{\mathsf T}(y-Xb)=0. \]

With full rank, \(X^{\mathsf T}e=0\) and the fitted vector is the orthogonal projection onto the columns of \(X\). QR factorization \(X=QR\) solves \(R\widehat b=Q^{\mathsf T}y\), avoiding an explicit normal-equation inversion. The browser uses modified Gram–Schmidt with a second orthogonalization pass and a rank threshold.

The omitted-factor slope

For a centered two-factor model, covariance with the market gives:

\[ \operatorname{Cov}(y,M) =\beta_M\operatorname{Var}(M)+\beta_V\operatorname{Cov}(V,M). \]

Dividing by market variance produces the restricted slope. This derivation requires orthogonality of the disturbance and market. Without it, another covariance term remains; adding a factor does not automatically repair endogeneity.

Portfolio and factor-mimicking exposures

For fixed weights, \(r_p=w^{\mathsf T}r\), so its factor sensitivity is \(B^{\mathsf T}w\). In a full-rank cross-sectional WLS model, coefficient extraction is a linear map:

\[ \widehat g=(X^{\mathsf T}WX)^{-1}X^{\mathsf T}WR. \]

Rows of that map define mathematical factor-mimicking stock weights. Economic constraints are not automatically respected. Factor replication with position limits or trading costs is a separate constrained portfolio problem.

Risk gradients

For \(\sigma=\sqrt{b^{\mathsf T}\Sigma_fb+v_\varepsilon}\), differentiation gives:

\[ \frac{\partial\sigma}{\partial b_k} =\frac{(\Sigma_fb)_k}{\sigma},\qquad \sum_k b_k\frac{\partial\sigma}{\partial b_k} +\frac{v_\varepsilon}{\sigma}=\sigma. \]

The residual term completes the attribution. If total variance is zero, normalized contributions and marginal volatility are undefined. The laboratory reports an undefined value rather than dividing by zero in that case.

A Python OLS/HAC reference

This function uses an independent SVD-based least-squares implementation and the same stated HAC normalization as the browser. Factor and target arrays should contain aligned monthly return decimals.

import numpy as np

def ols_hac(factors, target, lags=6):
    X = np.column_stack([np.ones(len(target)), factors])
    y = np.asarray(target, dtype=float)
    T, p = X.shape
    beta = np.linalg.lstsq(X, y, rcond=None)[0]
    residual = y - X @ beta
    bread = np.linalg.inv(X.T @ X)
    scores = X * residual[:, None]
    meat = scores.T @ scores
    for lag in range(1, lags + 1):
        cross = scores[lag:].T @ scores[:-lag]
        weight = 1 - lag / (lags + 1)
        meat += weight * (cross + cross.T)
    covariance = bread @ meat @ bread * T / (T - p)
    se = np.sqrt(np.maximum(0, np.diag(covariance)))
    return beta, residual, se

# Fit only a chronological training prefix.
# F is a T-by-K factor array; y is a T-vector of excess returns.
# beta, residual, se = ols_hac(F[:180], y[:180], lags=6)
# holdout_attribution = beta[0] + F[180:] @ beta[1:]

The explicit inverse is used here only for the small, full-rank covariance calculation. Larger or poorly conditioned applications should solve the corresponding systems or use a stable factorization. Detect rank deficiency before interpreting coefficient uncertainty.

Implementation checks

Verify residual orthogonality, intercept reconstruction, factor-scaling invariance and recovery of a noiseless full-rank model. Check the matched sample variance identity and sum of risk contributions. Confirm that long and short leg weights have their declared normalization and sector constraints.

Compare implementations using the same input observations and definitions. Differences in HAC bandwidth, finite-sample adjustment, return units or standardization can be legitimate convention differences rather than numerical failures. Those settings should be part of the reproducible result.

29 / Exercises

Exercises and worked solutions

Identify whether each quantity is a characteristic, a return sensitivity, an expected premium or a realized outcome. Expand a solution after attempting the calculation.

Exercise 1 — Match return units

A stock earns 2% in one month and the matched risk-free return is 0.3%. What is its excess return? What if the 0.3% field were annualized instead?

Solution. With a monthly risk-free return, excess return is 1.7%, or 0.017. An annualized field must first be converted under its compounding convention to the monthly interval. Subtracting it directly would mix units.

Exercise 2 — Compute market beta

A stock has volatility 6% per month, the market 4%, and correlation 0.5. Find beta and explain why beta is not stock volatility.

Solution. Beta is \(0.5(0.06/0.04)=0.75\). It measures market sensitivity. The 6% volatility includes residual variation that need not covary with the market.

Exercise 3 — Attribute one month's return

Alpha is 0.1%, market exposure 1.2 and value exposure 0.4. Market and value factors realize 2% and −1%. Observed excess return is 3%. Find fitted and residual return.

Solution. Fitted return is 0.1% + 1.2 × 2% + 0.4 × (−1%) = 2.1%. Residual return is 0.9%. These are realized attribution components, not known advance forecasts.

Exercise 4 — Rescale a factor

A factor series is multiplied by two while preserving the same model attribution. What happens to its beta and covariance terms?

Solution. Its beta is divided by two. Factor variance is multiplied by four and covariance with other factors by two. Attribution and total model variance remain unchanged when every transformation is applied consistently.

Exercise 5 — Reconstruct alpha

The portfolio mean excess return is 0.8% monthly. Market and value factor means are 0.5% and 0.2%, with estimated betas one and 0.5. Find alpha.

Solution. Alpha is 0.8% − 1 × 0.5% − 0.5 × 0.2% = 0.2% monthly. It is conditional on that factor benchmark and remains subject to estimation uncertainty.

Exercise 6 — Diagnose timing leakage

A June portfolio uses annual statements with a December fiscal-year label but a July publication date. Is the construction point in time?

Solution. No. The economic period does not establish availability. The July publication must occur before the formation decision or an appropriately dated earlier version must be used.

Exercise 7 — Distinguish neutrality constraints

A portfolio is long one dollar in assets with beta 1.3 and short one dollar in assets with beta 0.8. Is it dollar neutral? Is it beta neutral?

Solution. Net dollar weight is zero, but net market exposure is \(1.3-0.8=0.5\). Adjusting notional to remove beta generally changes dollar neutrality unless another financing or hedge position is included.

Exercise 8 — Explain a sort and a partial coefficient

A value tail portfolio returns 3%, while a joint regression's value coefficient is 0.8% per score unit. Must one result be wrong?

Solution. No. The tail spread has a particular score separation and may carry other style and sector exposures. The coefficient is a partial relation holding included controls fixed. Their units and conditioning differ.

Exercise 9 — Identify sector-dummy redundancy

Why does an intercept plus all four sector indicators create a rank-deficient cross-sectional design?

Solution. The four indicators sum to the intercept column. Omit a reference sector or impose an identifying constraint. Individual intercept and sector levels otherwise are not uniquely identified.

Exercise 10 — Compute omitted-factor bias

True market beta is one and value beta 0.6. Market–value covariance divided by market variance is 0.2. Find the market-only population slope.

Solution. The slope is \(1+0.6(0.2)=1.12\), assuming the disturbance is market-orthogonal. The restricted slope absorbs part of the omitted correlated factor.

Exercise 11 — Interpret HAC bandwidth

A model's coefficients stay fixed when the HAC lag count changes from zero to six, but its alpha standard error changes. Is that expected?

Solution. Yes. HAC estimates the covariance of the OLS estimator; it does not refit the point coefficients. Lag zero handles heteroskedasticity in the stated convention, and positive lags incorporate serial score dependence.

Exercise 12 — Calculate diversified risk

Stocks share 4% monthly common-factor volatility and independent 3% specific volatility. What is an equal-weight 25-stock portfolio's volatility?

Solution. Variance is \(0.04^2+0.03^2/25=0.001636\). Volatility is approximately 4.044750%. Adding volatility components directly would be incorrect; independent variance components add.

Exercise 13 — Interpret a negative risk contribution

A positive low-vol factor exposure has a negative Euler variance contribution. Does the factor have negative variance?

Solution. No. The contribution depends on covariance with the whole portfolio. A positive exposure can offset other risk and reduce total variance locally while standalone factor variance remains nonnegative.

Exercise 14 — Apply entry cost and validate claims

A long–short spread with gross exposure two returns 1.5% next month. Entry cost is 15 bp per traded unit from cash. What is the net snapshot return, and what costs remain absent?

Solution. Entry cost is 30 bp, or 0.3%, so net snapshot return is 1.2%. Borrow, financing, closing, later rebalancing and nonlinear impact remain absent. One period cannot establish a persistent net factor premium.

A final reading path

Reproduce the return identities and simple CAPM beta first. Then distinguish the style scores from traded-factor definitions, reconstruct a neutral tail portfolio and fit a return regression. Study HAC inference before interpreting alpha, and covariance attribution before using estimated exposures to hedge.

An empirical extension should begin with point-in-time data and a fixed research design. A trading extension should add feasible execution and financing. A risk extension should validate covariance forecasts and stress behavior. Each builds on these notes without treating a descriptive fit as a complete investment process.
